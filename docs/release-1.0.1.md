CellStation 1.0.1

- 网站无法连接或账号暂时登录失败时，也能启动调度并保持等待。
- 启动只检查本地运行环境、OCR、Chrome及预约配置；设置中的网站与账号检测为可选诊断，失败不阻止启动，也不发送微信。
- 到实际预约任务准备时重新连接、登录；保存前的短暂故障按设置重试，最终失败后按微信通知设置提醒。同一条失败结果去重，后续任务继续运行。
- 保留提前90秒准备、开放时提交、保存结果不明确时停止自动重试的行为。

验证：115项逻辑测试、3项更新事务测试、模拟离线界面、Windows EXE启动及本地OCR通过；不提交真实预约，不发送真实微信。便携包搬移及发布资产另行校验后交付。
