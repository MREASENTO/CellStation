微信通知

预约成功或失败后推送到微信，方便及时接管。先按下方教程绑定服务并获取密钥，再发送测试消息。

查看详细绑定教程与收不到消息的排查步骤
  1. 打开Server酱官方网站，用微信扫码登录；在“SendKey”页复制SCT开头的密钥。
  2. 在服务网站的“消息通道”中按指引绑定微信服务号并启用通道，用同一个微信账号扫码关注。仅登录网站不代表已绑定接收通道。
  3. 回到本程序，选择“Server酱 Turbo”，粘贴SendKey，移开输入框等待“所有更改已保存”。密钥采用Windows本机用户加密保存，不会显示回页面。
  4. 点击“发送微信测试消息”，在微信确认收到后勾选“开启微信通知”。可分别开启成功和失败提醒。
  5. 也可使用PushPlus官方网站，扫码登录、关注其公众号，复制token；本程序选择PushPlus并填入token，再测试。
  6. 收不到消息时：检查选对服务、复制完整密钥、通道是否绑定、公众号通知是否关闭以及服务剩余额度。预约条数较多，请先在服务网站核对当前额度和套餐；服务已接收不保证微信立刻送达。

推送包含日期、时段、设备、使用人和结果；不含登录密码、Cookie及截图。微信通知失败不会阻塞预约，执行记录仍保存在本机。更换Windows用户后可能需要重新填写密钥。

网站与账号检测（可选）

本地运行环境、Chrome与OCR在主窗口打开前检查；启动调度不要求网站连通或登录成功；实际任务准备时再连接、登录并检查仪器。

尚未自检
本地必要自检在每次打开程序时完成。网站或登录暂时失败也可启动等待；此处手动检测仅供参考，不发送微信。实际任务先按设置短间隔重试；网络/服务器故障按5分钟恢复原账号、原设备和原时段，使用开始后停止；已进入保存阶段仅查询核对。失败提醒按微信设置发送。检测不会提交预约。

失败诊断与人工核对

失败时保存输入框遮盖后的截图和诊断说明，不导出密码、Cookie或完整网页。执行记录中可按条导出诊断ZIP。

重试次数按程序设置执行。保存结果不明确时立即复核，首次未确认则按设置间隔再次复核；仍未确认停止并明确提醒自主复核。不会自动再次提交保存。
