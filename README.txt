CellStation 2.0.2 使用说明

一、复核与补约
1. 保存结果未确认时，立即进行首次复核。已查到本团队预约则直接更新结果，不再提交。
2. 首次复核未确认且“首次复核后尝试补约”已开启时，程序使用原账号、原设备和原时段，连续两次实时核对空闲，再最多额外保存一次。网站已占用、原计划修改、账号停用或使用时段开始时不提交。
3. 补约处理结束后立即再复核一次。确认存在即结束；仍未确认则等待设置的秒数，再进行最终复核。
4. 最终仍未确认时停止自动处理，并按通知设置发送【请自主复核】提醒。请在执行记录中点击“打开网页核对”，使用原账号核对网站记录。
5. 补约机会会写入本机记录，重启不会重置；补约保存结果不明确时也不会继续自动重复保存。网站记录可能存在延迟，程序通过实时查询和单次预算减少重复风险。
6. 程序设置中的“最终复核等待时间（秒）”支持正整数秒，修改后自动保存，运行中也可修改。旧版5分钟设置会换算为300秒；可改为10、20或其他所需秒数。
7. 执行记录分别显示原始保存、补约提交、补约后即时复核和最终复核时间，精确到毫秒。原始保存时间保留。

二、自动开始、暂停与开机启动
“程序设置 → 启动与系统提醒”提供相互独立的控制：
1. 按预约计划自动开始：开启后，即使当前调度尚未启动，也会在计划开放前自动启用并预热；仍需等到网站开放时才提交。设备日期限制、时段和账号设置继续生效。
2. 手动暂停后等待时间（秒）：默认1800秒（30分钟）。按计划自动开始已开启时，点击暂停会进入倒计时，到期自动恢复调度；再次暂停重新计时。修改秒数从最近一次暂停时刻重算。点击“立即开始预约”可提前恢复；关闭“按预约计划自动开始”则持续暂停，不再自动恢复。
3. 开机后自动启动程序：登录当前Windows用户后静默进入托盘，只控制程序是否启动。
4. 程序启动后自动开始预约：每次手动打开或开机启动后，完成本地检查即开始预约，不依赖上次是否运行；已有未结束的暂停倒计时优先，先等到期再恢复。
旧版“仅开机启动时恢复上次调度状态”保留在兼容选项中；未启用新的启动后自动开始时，仍可按上次状态恢复。
暂停倒计时会保存到本机，重启后继续保留；电脑休眠或程序关闭时无法执行，重新运行时若等待已结束会按当前计划恢复。等待期间可查看显眼的倒计时和预计恢复时间。
网络或网站登录失败不会阻止本地调度启用，实际任务仍按原重试、补尝试和复核流程执行；缺少账号、设备或本地环境不合格时保持暂停并显示原因。
按计划自动开始的开关和等待秒数纳入配置备份，不导出旧的运行倒计时。导入后保持暂停，若导入的自动开关开启，则新建一个完整等待期后恢复；桌面启动项及“程序启动后自动开始”仍为本机设置。
首次使用的新开关默认关闭；含本机配置的便携包也以暂停且新开关关闭交付。正式程序更新保留现有data配置和倒计时。

三、运行与账号

完整解压便携包到可写目录，双击CellStation.exe。关闭主窗口进入托盘；托盘退出才停止程序。保持电脑开机、联网且不休眠。
账号管理录入预约账号，最多启用5个；勾选需要预约的时段，系统每日随机分配。可直接调整每个时段的账号，修改后自动保存。多个启用设备按设置顺序依次预约。
团队人员无需账号密码；可从网站日历中的预约详情加入团队并绑定网站身份编号。团队已有预约会参与重复核对。
含本机配置的便携包调度初始为暂停。密码由Windows当前用户加密，换电脑或Windows用户后可能需重新输入。更新前先退出旧版。

四、设备日期、时段与网站日历
程序设置顶部的“预约仪器与设备计划”可按名称检索，或点击“检测设备”确认名称和预约日历能否识别。检测不保存预约。
每个设备展开“预约计划”，可选择不限日期、仅指定一天或起止日期范围；日期指实际使用日期，起止两天均包含。默认不限日期，保持原预约方式。
勾选“使用设备独立时段”后，可为五个窗口分别启用并修改起止时间；关闭此项则跟随通用窗口。时段在同一天内，采用整点或半点，启用窗口不能重叠；每次仍拆为30分钟，同一个窗口ID使用当日随机分配的账号。多个设备可使用不同的时间和日期。修改自动保存，运行中也可修改；保存前若原日期或时段已不再有效，会撤下旧准备任务。已在网站保存的预约不会因此取消。
网站日历保留今天前30天及今天至今天后第7天，共38天。首次升级补全缺失的历史周，后续每天刷新近期数据并只补充缺失历史，不会每日重读整月。补全在后台执行，临近预约时让位；尚未完成时可稍后点击“立即更新”。
每次预约或复核确认成功后直接复用网站读回的日历数据同步对应设备和周，无需额外登录或查询；相同团队记录继续复用，网站明确变动则更新。重启和翻页使用本地缓存。过去日期淡化、今日高亮，时间线即时更新。
本地缓存只用于展示，实际预约与复核仍实时读取网站；已超过30天的日历缓存自动移除，执行记录和真实回执按原规则保留。

五、微信提醒
支持Server酱Turbo和PushPlus。在相应服务网站登录并按指引绑定微信接收通道，复制SendKey或token到“程序设置 → 微信通知”，发送测试消息确认接收后开启通知。
Server酱Turbo：https://sct.ftqq.com/ 。PushPlus：https://www.pushplus.plus/ 。
最终需人工确认的提醒以【请自主复核】开头，与等待复核消息分别发送。服务接收不代表手机即时送达，异常信息可在设置查看。

六、备份与更新
配置备份包含账号、加密密码、团队人员、时段分配、复核等待秒数和首次补约开关。导入前需暂停调度，先预览再确认；执行记录和截图保留。
程序通过签名更新清单和CNB国内Git仓库更新应用，保留data目录；更新只在空闲时进行。完整移动整个便携目录可保留本机数据。
公开项目：https://github.com/MREASENTO/CellStation
国内仓库：https://cnb.cool/mreasento/CellStation

开机自启动诊断与修复
1. 在程序设置 → 启动与系统提醒中开启“开机后自动启动程序”，状态应显示“已验证”。
2. 程序会在当前Windows用户登录后在系统托盘后台启动，不弹出预约网页。关机或未登录时无法运行。
3. 若启动项缺失或程序路径改变，按保存的启用设置在下次打开时修复；移动程序后至少手动打开一次。
4. Windows任务管理器禁用的启动项不会被静默重新启用；请点击“重新注册启动项”手动恢复。
5. 预约是否自动开始仍由独立开关控制；已有暂停倒计时优先。关闭程序自启动开关后不会自动重新开启。
6. 启动方式、程序路径、启动项检查及就绪状态写入data/logs/desktop-日期.log，便于排查。

执行记录：手动重新预约
失败或已错过的记录显示“重新预约”。使用原账号、原设备及原时段，先核对网站已有预约，确认团队已预约时不重复提交。
可在调度暂停时单独执行，整体计划保持原状态；操作期间顶部显示单次任务状态，可点击“取消重新预约”阻止尚未发送的保存。
原始失败信息及步骤时间保留，新增本次开始、保存和确认时间。保存结果不明确时立即复核，仍未确认则进入等待最终复核；自动复核随预约调度运行。
使用时段已开始、尚未开放或原账号缺失时不能提交；原账号正在处理其他任务时请稍后重试。

企业微信群机器人通知
在程序设置下方“微信与企业微信通知”选择“企业微信群机器人（直连）”。在电脑企业微信内部群进入群设置 → 消息推送 → 自定义消息推送（部分版本显示群机器人 → 添加机器人），命名为CellStation预约提醒，复制完整Webhook地址。
将地址粘贴到本程序的Webhook密码框，移开输入框等待自动保存；点击发送通知测试消息，确认手机目标群收到后再开启通知及成功/失败提醒。
地址格式：https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=… 。完整地址属于密钥，只在本机填写，不发送到聊天或公开仓库。采用Windows当前用户加密保存，不回显。切换服务默认关闭通知并要求重新填写该服务的密钥。
消息发送到内部群，普通微信群及外部群不适用。没有机器人入口时请管理员核对内部群类型及权限。手机需登录同一企业、加入同一群，并开启企业微信通知、关闭群免打扰。
本程序按每条至少间隔3.1秒排队发送，兼容机器人20条/分钟的限制；预约提交不等待消息。通知待发送时推迟自动安装更新，主动退出程序会停止未发送队列。多个程序共用机器人时也会占用服务频率。
完整配置步骤和排查说明见程序设置内的展开教程。腾讯官方说明：https://cloud.tencent.com/document/product/248/50413 。
